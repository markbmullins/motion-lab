Linear homepage motion audit and interactive showcase
Audited: 7 October 2026

Open motion-audit.html directly in a browser. No installation or server is needed.
The interactive report embeds its CSS, JavaScript, original SVG illustrations,
and extracted motion data. Evidence images and source links use adjacent files.

14 interactive studies / 18 chapters. Replay, pause, slow playback, keyboard
scrubbing, channel controls, and a reduced-motion option are included.

Live observations and source facts are distinguished from teaching
reconstructions. Spring fits and simplified shells are labelled.
This is not a quantitative FPS or performance benchmark.

homepage-motion-data.json: extracted values, exact loader frames and runtime data
evidence/: source excerpts, matched CSS rules and asset records/hashes
live-*.jpg: captures of the actual Linear homepage
*-preview.png: screenshots of this audit
verification.json: browser checks
