01 / Read the page as a motion system

Small vocabulary. Deliberate composition.

Studio Lenzing combines recurring leftward entrances and white image curtains with a more expressive navigation system, a vector logo intro, a magnetic play button, and two kinds of overlay. Its desktop and phone homepages have different media behavior.

Webflow IX2

CSS transitions

Desktop Updates, mobile navigation, showreel layers, hover colors, and story progress smoothing.

Custom JavaScript

GSAP magnetic movement; direct cursor positioning; Vimeo playback and progress; Lottie artwork playback.

04 / Image reveals + hover

The picture stays still. A white curtain leaves.

The cover is a child inside a clipped figure. It begins at translateX(0%) and travels to translateX(100%) over 1200 ms, with inOutExpo. That percentage is the cover’s own width. The cover stays display:block after the tween; it is outside the visible figure.

06 / Pointer response

Magnetic movement and cursor following are different.

The magnetic hit area is the whole desktop showreel. Its button targets x = (pointerX / width − 0.5) × 50 and the equivalent y. This limits travel to ±25 px on either axis. Every mousemove starts a 1 s GSAP tween with power4.out; leaving targets zero with the same tween.

Pointer study

Move across the full hit area

Use the corner buttons for repeatable targets or move the mouse. This reconstruction retargets from the current position; the source calls gsap.to() without an explicit overwrite option.

Full region is magnetic

Source press scale: 1 → 0.95 over 100 ms; return 100 ms. No explicit ease is supplied for those two tweens.

The project tooltip and contact close cursor instead write fixed left/top coordinates directly. Their positions do not interpolate. The project tooltip jumps on enter/leave; the custom image cursor is a static bitmap. The magnetic button is the part that deliberately lags behind the pointer.

10 / Phone video stories

Playback progress, not a decorative timer.

Below 768 px the homepage presents three portrait Vimeo panels. The first starts muted when loaded; looping is disabled on each player. A timeupdate listener sets the active bar’s width to seconds / duration × 100%. At video end it advances to the next panel and wraps after the third.

Media simulation

Step through a three-story strip

These are synthetic 6-second stories for studying the control logic. Six seconds is not the measured duration of the original films.

Story 01Progress follows media time.

Previous/next pauses the old player, changes translateX to −index × 100%, seeks the new player to zero, and plays it. Earlier bars become full; the current bar resets; future bars hide. On the inspected page the slides container has no nonzero transition duration, so panels cut rather than glide. Width alone has a 200 ms linear transition.

The source does not gate these Vimeo players on intersection in this script. Desktop hides the story strip with display:none. Embedded film content has its own motion; this audit covers the webpage’s playback, navigation, and reveal behavior, not a frame-by-frame breakdown of the films.

13 / Rebuilding the craft

Copy the relationships before choosing the library.

The core vocabulary is translate, opacity, scale, clipping, stagger, and state-dependent delays. You can rebuild it with CSS transitions plus IntersectionObserver and a small pointer loop. Webflow is an authoring layer; its published behavior is inspectable.

Motion for React can make variants, exit completion, and stagger orchestration easier to maintain. GSAP is already used here for magnetic movement. Neither library automatically supplies the timing, geometry, or restraint. Preserve the values and coordination first, then pick the orchestration tool that fits your application.

Preserve

Per-channel easing, full-width percentage curtains, independent intersection triggers, and asymmetric open/close delays.

Improve deliberately

Retarget pointer tweens safely; pause offscreen media; remove unmatched legacy code; give custom controls keyboard semantics and visible focus.

Measure

Transform/opacity avoid layout changes in these recipes, but Vimeo, blur, SVG updates, and permanent will-change still have costs. Profile on target hardware.

No FPS, CPU, GPU, or Core Web Vitals score is asserted here. This audit verified behavior and computed values, not a Chrome performance trace. Smoothness on one machine is not a performance certificate.

For a production recreation, also add prefers-reduced-motion behavior and robust overlay focus/scroll management. The study document honors the operating-system reduced-motion preference and offers an explicit opt-in to replay motion.
